# CodJam-Leg4

**An ongoing improvement project for the original LEGAL 3 robotics programming environment.**

CodJam-Leg4 explores ways to modernize the original LEGAL experience while preserving its educational focus: helping users program robots. The goal is to make the project easier to understand, maintain, and improve over time.

## Development status

**Early development — research and modernization in progress.**

The current work focuses on understanding the legacy application, documenting the original language, and organizing the next steps. A reproducible build, complete source-code recovery, stable release, and end-to-end validation with the robot have not yet been established.

CodJam-Leg4 should therefore be considered a work in progress, not a ready-to-use replacement for the original software. Proposed improvements are goals, not a claim that every feature has already been implemented.

## Development and maintenance

The project is developed and maintained by the project maintainer with assistance from **ChatGPT** and **Claude Code** as AI development tools. Project direction, review, validation, and release decisions remain under the maintainer's responsibility.
